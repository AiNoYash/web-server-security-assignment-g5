Security Analysis & Viva Reference

Root Cause (Vulnerable Route)

User input is concatenated directly into the SQL command text via Python f-strings. A single quote (') inside user input terminates the string literal early, allowing input tokens to be parsed as SQL keywords (OR), tautologies ('1'='1'), or comment markers (--).

Implemented Mitigation (Secure Route)

Parameterized queries with ? placeholders enforce compile-time separation between code and data. The database engine compiles the query syntax tree beforehand; user inputs are bound strictly as data literals and cannot alter the query structure.

Error-Based Information Leakage

Entering a trailing single quote (admin') in the vulnerable endpoint triggers a raw SQLite syntax error (HTTP 400). Exposing raw database exceptions reveals underlying schema and engine information to clients (CWE-209).
